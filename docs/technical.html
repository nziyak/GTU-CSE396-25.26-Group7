PROTOCOL SPECIFICATION

Communication Protocol

Commands (Pi → Mega)

ASCII commands terminated by \n. Mega executes movement for 2 seconds, then auto-stops.

CommandBehavior
FORWARD\nMove forward for 2 seconds
BACKWARD\nMove backward for 2 seconds
LEFT\nTank-turn left for 2 seconds
RIGHT\nTank-turn right for 2 seconds
STOP\nImmediate stop

Telemetry (Mega → Pi) — Every 300ms

{"dist_front": 45, "dist_back": 80, "mic1": 340, "mic2": 335, "smoke": 420, "yaw": 1.2, "pitch": -0.5, "roll": 0.3, "temp": 24.5, "hum": 45.0, "connected": true}
FieldTypeDescription

smokeintMQ-2 smoke sensor raw value (0-1023)
